# node-util-scripts

A collection of Node.js utility scripts for common automation tasks.

## What's inside

- **Feed sync** — periodically fetch and aggregate RSS/Atom feeds
- **Web scan** — search public engines for trending topics
- **Media index** — index YouTube channels via yt-dlp
- **Community scan** — monitor social media platforms

## Setup

1. Fork or clone this repo
2. Configure repository secrets (see `.github/workflows/` for required vars)
3. Enable GitHub Actions
